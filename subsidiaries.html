FileCura

// 01 software · macOS

A local-first workflow platform for Mac. FileCura turns Finder into a workflow engine — automating the file work that usually means scripts, Automator, or a second app.

01

Right in Finder

Every workflow ships as a Finder Quick Action — discoverable in the right-click menu across every folder.

02

Local-first, zero telemetry

Files stay on your Mac. No cloud account, no subscription, no analytics — ever.

03

Free app, paid packs

One-time purchase, lifetime licence. Routing, project automation, metadata, file hygiene — pick what you need.

Reflow

// 04 apps · out now

Veratus Group's first consumer app. Photograph or scan a room, pick how you want it to feel, and Reflow returns a plain-English move list for the furniture you already own — then shows the result as an interactive 3D floor plan. No shopping required.

01

Works with what you own

It rearranges your existing furniture instead of trying to sell you more — swap suggestions stay optional.

02

Real geometry, not guesswork

A deterministic layout engine keeps every suggestion physically sensible — clearances, walkways and doorways included.

03

See it in 3D first

An interactive before-and-after floor plan shows the outcome before you lift a thing.
